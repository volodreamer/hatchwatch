Оновлено 7 вересня 2026. Ця сторінка для вебзастосунку volodreamer.github.io/hatchwatch.

English Українська

← Hatchwatch

Hatchwatch is a Tamagotchi Gen 1 care companion. You log hatch time and button presses; it tracks hearts, discipline, and the 15-minute care window. It runs in your browser. There is no Hatchwatch account server.
Hatchwatch — супутник догляду за Tamagotchi 1-го покоління. Ти фіксуєш час вилуплення і натискання кнопок; він стежить за серцями, дисципліною і 15-хвилинним вікном. Працює в браузері. Окремого сервера облікових записів Hatchwatch немає.

Data on this device

Дані на цьому пристрої

The pet run (hearts, discipline, care log, settings) is stored in this browser as hatchwatch-v1. Language and shell theme are stored locally too. File backup (Save file / Copy short) never leaves the phone unless you copy or send the file yourself.

Забіг (серця, дисципліна, журнал, налаштування) лежить у цьому браузері як hatchwatch-v1. Мова і колір корпуса теж локально. Файл копії (Зберегти файл / Коротка копія) нікуди не йде, поки ти сам його не скопіюєш або не надішлеш.

Optional Google backup

Необов’язкова копія в Google

Sign in with Google is optional. File backup works without it. If you sign in, Hatchwatch asks Google for:

Вхід через Google необов’язковий. Файл копії працює без нього. Якщо увійти, Hatchwatch просить у Google:

  • Your email address — shown in Settings as “signed in as …”, also kept in this browser as hatchwatch-google-email.
  • Адресу пошти — показується в Налаштуваннях як «увійшов як …», також у цьому браузері як hatchwatch-google-email.
  • Drive app data only — a hidden app folder, not your normal Drive files, photos, or Docs. Hatchwatch writes one JSON file named hatchwatch.json (the same payload as Save file). While you stay signed in with this tab open, that file updates as the run changes.
  • Лише дані застосунку Drive — прихована папка, не звичайні файли Drive, фото чи Docs. Hatchwatch пише один JSON hatchwatch.json (той самий вміст, що й «Зберегти файл»). Поки ти лишаєшся в системі і вкладка відкрита, цей файл оновлюється разом із забігом.

The Google access token is kept in memory for this tab. It is not written to disk. Hatchwatch does not request full Drive access, Gmail, Calendar, or contacts.

Токен Google тримається в пам’яті цієї вкладки. На диск не пишеться. Hatchwatch не просить повний доступ до Drive, Gmail, Календаря чи контактів.

What we do not do

Чого ми не робимо

  • No ads. No sale of personal data. No Hatchwatch cloud database of pets or emails.
  • Без реклами. Без продажу персональних даних. Немає хмарної бази Hatchwatch із забігами чи поштами.
  • We do not share Google user data with other companies. Google (sign-in and Drive) and GitHub Pages (hosting this site) process requests under their own policies.
  • Ми не передаємо дані Google іншим компаніям. Google (вхід і Drive) і GitHub Pages (хостинг) обробляють запити за своїми політиками.

How long it stays

Скільки це зберігається

Local data stays until you End run, clear this site’s data, or overwrite it with a restore. The Drive app-data copy stays in your Google account until you overwrite it from Hatchwatch or remove Hatchwatch’s access. Revoking access stops new reads and writes; it does not always delete the hidden file automatically.

Локальні дані лишаються, поки не натиснеш «Завершити забіг», не очистиш дані сайту або не перезапишеш відновленням. Копія в Drive лишається в акаунті Google, поки не перезапишеш її з Hatchwatch або не прибереш доступ. Відкликання доступу зупиняє нові читання й записи; прихований файл сам не завжди зникає.

Your controls

Твої дії

  • Sign out in Hatchwatch Settings.
  • Вийти в Налаштуваннях Hatchwatch.
  • Revoke Hatchwatch at Google Account → Third-party access.
  • Відкликати Hatchwatch у акаунті Google → Доступ сторонніх додатків.
  • Delete the local run with End run, or clear site data in the browser.
  • Видалити локальний забіг кнопкою «Завершити забіг» або очистити дані сайту в браузері.

Children

Діти

Hatchwatch is a care log for a toy. Do not use Google sign-in with a child account. Google may block those accounts from granting Drive app data.

Hatchwatch — журнал догляду за іграшкою. Не входь через Google з дитячого акаунта. Google може заборонити таким акаунтам доступ до даних застосунку Drive.
