# hatchwatch
HatchWatch — a Gen 1 care companion for the physical shell. Pick who you want to grow, log the hatch, and it watches hearts, discipline, and the 15-minute window so the device does not beat you.

How a run works

Pick the adult (Mametchi through Bill / Oyajitchi).
Say when it hatched — just now, clock just set (egg in ~5 min), or an exact time.
Log what you actually press on the shell: meal, snack, game, clean, scold, medicine, lights.
The LCD tracks hunger/happy hearts, discipline, weight, poop, and the mistake budget for your target.
When a call is open you get a ticking 15-minute window plus the button to press (e.g. Food → Meal).

What it knows (original P1 internals)

1. Heart drain per character (Babytchi 3/4 min, Marutchi 50/60, Maskutchi 55/65, …)
2. Sleep clocks (Marutchi 8pm, Maskutchi 11pm–11am, …)
3. Care mistakes vs discipline mistakes, and how they pick Tamatchi type 1/2 → each adult
4. Secret path: never scold, good care, type-2 Maskutchi, wait ~4 days → Bill (EN) or Oyajitchi (JP)
5. Poop and sickness do not beep on the real device — Hatchwatch still reminds you

Try it

- Preview a Marutchi run to jump into a live dashboard aimed at Mametchi.
- Or start a real run: pick Mametchi, “It just hatched”, then hit Meal immediately — both meters start empty.
- Match device copies the status screens if you join mid-run.
- Plan is the full path + mistake budget. Guide is every character’s drain/sleep/shots table.

Keep Hatchwatch open (or installed) for beeps — the shell still needs you to press the real buttons; this is the sitter that does not miss the window (web app notification still isn't very reliable).
